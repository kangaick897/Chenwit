# Client Setup

This is the entry point for setting up a new client site from this template. Read [the complete client deployment runbook](docs/CLIENT_SETUP.md) before making changes, then follow its gates in order.

If an AI assistant is handling setup, first inspect the cloned repository and ask for missing client details one step at a time. Do not invent values or reuse the current client's Supabase project. Keep secrets out of Git, verify each setup gate, and distinguish prepared instructions from steps actually tested on the new client's infrastructure.

The starter images and copy are not a finished client website. Replace client-specific content only with approved assets and details. Do not apply SQL to an existing populated database or change live DNS without confirming the target and obtaining the owner's approval.
